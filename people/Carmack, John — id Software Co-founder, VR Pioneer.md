# John Carmack — Programming Genius, VR Pioneer, id Software Co-founder

**The most important programmer in video game history.** Carmack's graphics innovations — from adaptive tile refresh in Commander Keen to the 3D engines powering Wolfenstein 3D, DOOM, and Quake — enabled the first-person shooter genre and influenced all of 3D computer graphics.

## Career arc

- **1990:** Joined the group that became id Software. Programmer on Commander Keen (first smooth-scrolling PC platformer).
- **1991:** Co-founded id Software with John Romero, Adrian Carmack, and Tom Hall.
- **1992:** Lead programmer on Wolfenstein 3D — breakthrough FPS with ray-casting engine.
- **1993:** Lead programmer on DOOM — revolutionary 3D engine; Carmack's Reverse shadow volume technique developed around this era.
- **1996:** Lead programmer on Quake — first true-3D FPS engine. Quake's online multiplayer networking code set standards.
- **1997–2010:** Continued leading engine development through Quake II, Quake III Arena, DOOM 3, and id Tech 4/5. Released engine source code under GPL.
- **2013:** Left id Software after 22 years. Joined Oculus VR as CTO — believed VR would be the next transformative computing platform.
- **2014:** Oculus acquired by Facebook/Meta for $2B. Carmack continued as CTO.
- **2019:** Reduced role to Consulting CTO to focus on artificial general intelligence (AGI) research.
- **2022:** Left Oculus entirely. Founded Keen Technologies, an AGI research company.
- **2023–2026:** Keen Technologies raised funding; Carmack continues AGI work, occasionally comments on game and VR industry.

## Key contributions

| Technology | Year | Significance |
|---|---|---|
| Commander Keen engine | 1990 | PC smooth-scrolling breakthrough |
| Wolfenstein 3D engine | 1992 | Layered ray-casting; FPS foundation |
| DOOM engine | 1993 | BSP trees; virtual 3D space |
| Quake engine | 1996 | True 3D; network multiplayer |
| id Tech (2..5) | 1997–2010 | Licensed engines; industry standards |
| Carmack's Reverse | 2000s | Stencil shadow volumes |
| Oculus VR SDK | 2014–2019 | Mobile VR (Gear VR, Quest) |

- **Carmack's Reverse:** A technique for rendering stencil shadow volumes using depth buffers — became an industry standard.
- **Open-source advocacy:** Carmack released id Tech source code under the GPL (starting with DOOM in 1997, Quake in 1999). This enabled mod communities and countless derivative projects.
- **VR development:** At Oculus, Carmack was instrumental in making mobile VR viable (Gear VR, Oculus Go) and contributed significantly to Quest hardware/software.
- **AGI pivot:** Carmack's belief that AGI is the most important technical challenge led him to leave game development entirely after 2022.

## Labour context

- Carmack has never been involved with union organizing. His public statements on labour lean libertarian — he has expressed skepticism about collective bargaining in tech while emphasizing individual merit and productivity.
- At id Software, the structure was flat and unstructured — Carmack famously worked alone on core engine code, rarely interfacing with the broader team.
- Carmack has been critical of corporate inefficiency and bureaucracy — his frustration with Meta's management contributed to his departure.
- His relationship with [[people/John Romero]] fractured over creative direction (Romero wanted more ambitious game design; Carmack prioritized technology). This split led to Romero's departure after Quake.
