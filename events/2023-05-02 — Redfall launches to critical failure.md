# 2023-05 — Redfall launches to critical failure

**May 2, 2023.** Arkane Austin's Redfall launched to poor reviews — Metacritic scores of 54–64/100 across platforms. The game was criticized for technical issues (30fps lock on Xbox), repetitive gameplay, and poor implementation of looter-shooter mechanics.

The failure was widely seen as contributing to Microsoft's decision to close Arkane Austin one year later (May 7, 2024), along with Tango Gameworks and Alpha Dog Games. Arkane Lyon, which was developing Marvel's Blade, survived the closures.
