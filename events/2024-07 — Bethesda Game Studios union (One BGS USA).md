# 2024-07 — Bethesda Game Studios wall-to-wall union formation (One BGS USA)

**First 'wall-to-wall' union at any Microsoft game studio.** 241 artists, engineers, programmers, and designers across BGS Dallas, Rockville, and Austin formed One BGS USA under CWA. Microsoft voluntarily recognized the union.
