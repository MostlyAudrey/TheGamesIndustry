# Project Gamecraft — Games Industry Power Map

> A source-cited, cross-linked map of the games industry's **money, labor, and power**. Built for a union leader to act on.
> **Geography: US + Canada.** **Capital-first** (PE + big-name VCs → portfolio studios → leaders → labor).
> Status: skeleton (2026-10-15). Research pending seed list.

## How to read this map

This is a **graph**, not a directory. The value is in the **edges** between nodes.

- **[[orgs/...]]** — the backbone: PE/VC funds, publishers, studios, unions.
- **[[people/...]]** — the actors: leadership, funders, union officers.
- **[[events/...]]** — what makes it a *power* map: deals, strikes, layoffs, board changes.
- **[[sources/...]]** — the evidence layer. Every claim traces here.

**Edge types** (recorded bidirectionally):
`funded-by` / `portfolio-of` · `acquired-by` · `board-member-of` · `was-CEO-of` · `succeeded-by` · `unionized-with` · `recruited` / `fired` · `negotiated-with` · `lp-in`

**The capital chain** (the main thread): `LPs (pensions/endowments/family offices) → PE/VC fund → portfolio studio → leaders → labor`. This is "see how the money is connected."
